# pipe-rack-ar

AR viewers (model-viewer) for three pipe rack SketchUp models.

- [pipe rack 1](model1.html)
- [Installation of a pipe rack](model2.html)
- [piperack industrie](model3.html)
- [AR test: Astronaut (Google sample)](test.html)

Pages use `ar-modes="webxr quick-look"` (in-browser AR, no app needed) and show an on-page AR diagnostics log.
